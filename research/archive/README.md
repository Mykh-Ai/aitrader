# research/archive

Created: 2026-05-16

Archive area for diagnostics that are no longer active candidate evidence.

This sprint did not move existing files from `research/findings/` or `research/results/` because the tree has hundreds of artifacts and moving them without a traceability manifest would increase audit risk.

Future archive moves must preserve:

- original path,
- new path,
- reason for archive,
- related candidate or rejected family,
- date moved.
